# کپسول ⏳

شبکه‌ی کپسول زمان: پیام یا عکس را قفل کن و در تاریخ دلخواه باز کن. نسخه‌ی اول کاملاً استاتیک است (بدون سرور).

## انتشار روی GitHub Pages
1. یک مخزن جدید در GitHub بساز و همه‌ی این فایل‌ها را در شاخه‌ی `main` بگذار.
2. در **Settings ← Pages** گزینه‌ی **Source** را روی **GitHub Actions** بگذار.
3. با هر push، سایت خودکار در `https://USERNAME.github.io/REPO/` منتشر می‌شود.

## اجرای محلی
`python3 -m http.server 8000` و باز کردن `http://localhost:8000`

## محدودیت‌های نسخه‌ی اول
- داده‌ها در `localStorage` مرورگر می‌مانند؛ برای انتقال از «پشتیبان/بازیابی» استفاده کن.
- قفل بودن بر اساس ساعت دستگاه است و پیام رمزنگاری نشده؛ برای امنیت واقعی باید سرور داشته باشی.
- لینک اشتراک فقط متن را می‌فرستد.

## گام بعدی برای تبدیل به محصول واقعی
- بک‌اند (Supabase یا Firebase): حساب کاربری، ذخیره‌ی ابری، قفل سمت سرور
- رمزنگاری سمت کاربر (Web Crypto) و باز شدن فقط با کلید زمانی
- ایمیل/اعلان روز باز شدن، کپسول گروهی، PWA
